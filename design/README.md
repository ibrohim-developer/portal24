# Design drop folder

Not part of the build. Put the Figma output here so the landing page
can be built to match it.

## screens/
Full-page PNG exports from Figma, 2x scale.
Name them by section or breakpoint, e.g.:
  desktop-1440.png
  mobile-390.png

## assets/
Logo (SVG preferred), icons, and any photos used in the design.

## Also needed
Font names used in the design, and whether they are Google Fonts
or licensed files you will provide.
